# Ahmadreza Ghanbari — Personal Website

Static Next.js (App Router) portfolio for [Ahmadrezagh](https://github.com/Ahmadrezagh), deployed to GitHub Pages.

**Live:** https://ahmadrezagh.github.io

## Stack

- Next.js App Router + TypeScript + Tailwind CSS
- Static export (`output: 'export'`) for GitHub Pages
- GitHub Actions deploy on push to `main`

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
# output in ./out
```

Content is seeded from the NewPersonal2025 portfolio project and the GitHub profile README.
